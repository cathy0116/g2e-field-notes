## 資料管理

「更多 → 資料與備份 → 資料管理」提供兩種操作：

- 清除未修改的事前資料：先預覽清單，保留個人新增／修改、筆記、個人附件、已看或封存、草稿關聯及不確定的紀錄，保留共用附件、賭場、詞彙及廠商。
- 重置全部資料：先下載備份，再勾選確認並輸入「重置」。清除本機全部紀錄、草稿、附件、廠商、詞彙與本機設定；App 程式及離線快取保留。

操作只影響目前裝置。刪除無法復原；可從先前下載的備份還原，但舊備份也會帶回舊項目。更換資料包先清除未修改事前資料，再匯入新版。更新版本本身不會清除資料。

## iPhone 快速開始

1. Safari 開啟 App，分享 → 加入主畫面，之後固定從圖示開啟。
2. 私人資料包先存到手機「檔案」，在 App「資料與備份」選檔匯入。
3. 下載離線資料，再開飛航模式測試查看及新增紀錄。
4. 點「記錄」，選擇「機台記錄」或「賭場觀察」；儲存後在「我的」查閱。
5. 收工先儲存草稿，再製作完整備份 → 分享／存到檔案，確認真的存好。

## 備份與安全

不每天備份不會自動清空資料；可以回國再匯出，但若手機遺失、故障、網站資料被清除或儲存異常，可能失去整趟紀錄。建議每天或重要訪查結束後備份，並在公司允許的位置保留手機以外的一份。

完整 JSON 包含機台、賭場、廠商、詞彙、筆記與引用的照片原檔。已儲存紀錄引用的錄音包含在內；草稿、未加入 App 的外部錄音和影片不包含。CSV 僅為機台文字表，不能取代完整備份。

兩人各自保存，不會自動同步。同 ID 還原使用較新時間優先，不是多人無損合併；回程整理前保留雙方原始備份。

此專案只發布空白 App 程式及公開教學。匯入內容只存目前裝置，不上傳 GitHub；備份未加密，請勿將私人資料包、備份、研究圖片或內部字典提交到此公開專案。

## 更新

v2.1 已加入賭場觀察與離線使用教學；v2.2 再加入下列速記、地點、錄音與更新功能。原本的本機資料庫保留；新版可讀舊資料包，v2.2 匯出的新版備份需用 v2.2 或更新版本。

更新前先備份、儲存草稿。在「資料與備份」檢查更新；確認版號 v2.4.0 後重新下載離線資料。不要用清除網站資料的方式更新。

## v2.4 介面更新

青綠配色、淡黃「★ 必看」。圖鑑依廠商分組，組內左圖右文，可收合。上方保留搜尋、全部／必看／未看快捷篩選；「篩選」包含廠商、地點、狀態、EKG 玩法、作品與產品類型，跨群組套用。選中的條件可個別移除或全部清除。廠商選單合併同公司分支，加入 MERKUR；來源資料保留。本機資料庫與備份格式不變。

同事可用 Safari 開啟相同公開網址、加入主畫面，再各自匯入公司允許分享的私人資料包。網站不需要 GitHub 登入，不會同步另一支手機的內容。公司是否允許在私人帳號代管工具及如何分享資料包，請依內部政策確認。更換網站網域前先匯出完整備份；新網域不會自動取得舊網域的本機資料。

## v2.2 新功能

- 極簡速記預設只顯示現場必要欄位，詳細欄位可展開。
- 記住目前地點，套用下一筆新機台；既有資料不改動。
- 機台與賭場可加入錄音附件、播放、下載，完整 JSON 含音檔。
- 直接錄音為試用功能，最長 3 分鐘；請先在實際 iPhone 試錄試聽，勿鎖屏或切背景。
- 資料與備份顯示版本並提供檢查更新。新版備份 schema 3，可讀舊 schema 1/2，舊 App 不能讀新備份。

## v2.3 介面更新

四個分頁：圖鑑、記錄、我的、更多。機台與賭場共用新增入口；我的頁面提供草稿刪除及封存還原／永久刪除。刪除前會確認，僅清除不再被其他紀錄引用的附件。資料庫與備份格式不變。
